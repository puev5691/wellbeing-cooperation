# Source card v0.1

Обязательные поля:

`source_id`, author, title, date, source_type, origin, locator, version/commit, sha256 if bytes available, rights/access state, abstract, themes, variant/duplicate links, verification state, fact-check notes.

Правило: если точная дата, автор или происхождение не подтверждены, писать `unknown`, а не реконструировать.
