# КООПЕРАЦИЯ

Долговременный исследовательский корпус проекта «Благополучие» по кооперации, совладению, федеративным моделям, системе Чартаева, работам Бобровского, коллективной субъектности и организационным технологиям.

## Принцип

Источник не равен утверждению. Утверждение не равно выводу проекта. Публикация не равна доказательству.

Конвейер:

`source intake → identity/provenance → dedupe/variant → source card → claim extraction → verification → contradiction map → evidence matrix → synthesis → speech/pilot`

## Структура

- `sources/primary/` — первичные и исторические источники, только после проверки provenance и прав на публикацию;
- `sources/secondary/` — исследования и поздние интерпретации;
- `registry/` — реестр источников;
- `cards/` — нормализованные карточки источников;
- `claims/` — candidate/verified claims;
- `cases/` — практические кейсы;
- `maps/` — тематические и концептуальные карты;
- `speech/` — evidence-first материалы выступлений;
- `ops/` — правила процесса, схемы и контрольные документы.

## Статусы

Source: `located | ingested | normalized | verified_identity | superseded | rights_unknown | inaccessible`.

Claim: `candidate | supported | contradicted | unresolved | rejected | superseded`.

Не использовать `approved` для source/claim без отдельно определённого процесса approval.

## Публичность

Этот репозиторий публичный. Оригиналы источников с неразрешённым `rights_state` сюда не публикуются. До отдельной проверки прав допускаются только библиографические записи, аналитические карточки, собственные выводы проекта и короткие допустимые цитаты.
